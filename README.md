One letter for my day: **D** — for *doomscrolling*. The phone glowing at
2 a.m., thumb scrolling disaster after disaster, unable to stop. The
program writes exactly that one letter, and nothing else, to
`entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
